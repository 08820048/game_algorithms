[上一章](/procgen/noise/)的 Value Noise 和 Perlin Noise 留下了两个问题：

1. **格点的痕迹**。两者都建立在正方形格子上，统计性质随"在格子里的位置"变化；Value Noise 的梯度还强烈偏向坐标轴。
2. **只有一种尺度**。单层噪声每隔一两个格子起伏一次，看起来像均匀的波纹，不像山脉——真实的地形是大起伏上叠着小起伏，再叠着更小的起伏。

这一章用三种工具回答它们：**Simplex 噪声**换掉正方形格子；**Worley 噪声**提供一种完全不同的图案；**分形布朗运动**（fBm）把多层噪声叠加成多尺度的起伏。

## Simplex 噪声

Perlin 在 2001 年提出了 Simplex 噪声，目标是去掉正方形格子的方向性，并降低高维时的开销。

二维 Perlin 噪声要混合正方形的 4 个角，三维要混合立方体的 8 个角，N 维要 2^N 个角。Simplex 噪声改用**单纯形**（simplex）：二维是三角形，三维是四面体，N 维只有 N + 1 个顶点。

怎样把平面切成三角形，又能像正方形格子一样快速找到所在的格子？办法是**斜切**：把正方形格子沿对角线方向压扁，每个正方形就变成两个等边三角形。反过来，把采样点"拉伸"回正方形格子的坐标，就能用 `floor` 找到所在的正方形，再比较 x、y 的大小判断是上三角形还是下三角形。

第二个变化是**不再插值**。每个角的贡献是

```
(r0² − |d|²)⁴ · (g · d)
```

其中 d 是从这个角指向采样点的向量，g 是这个角的梯度。`g · d` 与 Perlin 相同；前面的因子随距离衰减，在 |d| = r0 处变成 0。三个角的贡献直接相加，没有任何沿坐标轴进行的步骤，这就是它方向性小的原因。

### 影响半径：为什么是 0.5

r0² 取多少？三角形的边长是 √(2/3) ≈ 0.816，高是 √2/2 ≈ 0.707。采样点在三角形内时，三角形外最近的顶点（隔着一条边的那个）离它至少是一个"高"的距离。所以只要 **r0² ≤ 0.5**，三角形外的顶点就永远够不着，只算 3 个角是精确的。

测试用暴力写法验证了这一点：枚举附近 7×7 个斜切格子的全部顶点，凡是在半径内的都算贡献，不判断采样点在哪个三角形里。30,000 个随机点上，它与只算 3 个角的版本最大相差 10⁻¹⁰ 以内。

网上流传的一些二维实现用的是 r0² = 0.6。这时三角形外的顶点进入了半径，但代码仍然只算 3 个角，跨过三角形的边时就会出现断层。实测跨过对角边时值与梯度的跳变：

| r0² | 有跳变的边 | 值的跳变（最大，相对标准差） | 梯度的跳变（平均 / 最大，相对平均梯度） |
|---|---|---|---|
| 0.50 | 0% | 0 | 0 / 0 |
| 0.55 | 41.6% | 0.001 | 0.002 / 0.016 |
| 0.60 | 63.0% | 0.012 | 0.013 / 0.088 |

断层确实存在，但比我预想的小：值最多跳变标准差的 1.2%，梯度最多跳变平均值的 9%。原因是漏掉的顶点离得最近时贡献也只有 (0.6 − 0.5)⁴ 量级。肉眼看灰度图很难发现，但用梯度打光、或者用噪声做位移贴图时可能显现。没有理由冒这个险：用 0.5。

### 缩放系数

每个角的贡献最大只有 0.01 左右，所以要乘一个缩放系数让输出落在 [−1, 1]。常见的实现里写着 70，那是针对另一组梯度（12 个不归一化的向量）算出来的；梯度集合换了，系数也得重算。这里用数值搜索：对斜切格子 4 个角的 8⁴ = 4096 种梯度组合，在格子内的网格上找最大值，再局部细化，得到最大值 0.0100802，所以系数取 1/0.0100802 ≈ 99.2。测试中再次穷举 4096 种组合确认不超过 1，并且能取到 0.999 以上；最大值出现在两个三角形公共边的中点附近。

### 方向性

上一章用梯度方向的分布衡量方向性：E[cos 4θ] 衡量偏向正方形格子的坐标轴（90° 对称），E[cos 6θ] 衡量偏向三角形格子的方向（60° 对称）。再加上沿 0°、30°、45° 方向相距 1 的两点的相关系数：

| 噪声 | E[cos 4θ] | E[cos 6θ] | 相关系数 0° / 30° / 45° | 最大差 |
|---|---|---|---|---|
| Value | +0.445 | +0.001 | — | — |
| Perlin | −0.074 | 0.000 | −0.134 / −0.164 / −0.174 | 0.040 |
| Simplex | −0.001 | +0.001 | −0.0052 / −0.0057 / −0.0059 | 0.0007 |

Simplex 在两项指标上都几乎完全各向同性。我原本担心三角形网格会带来 60° 的方向偏差，实测没有（cos 6θ 为 0.001）。

### 速度：二维时并不更快

| 实现（float，每次采样） | 用时 |
|---|---|
| Perlin，置换表 | 2.5 ns |
| Perlin，整数哈希 | 7.1 ns |
| Simplex，置换表 | 8.3 ns |
| Simplex，整数哈希 | 10.8 ns |
| Simplex，整数哈希，同时求梯度 | 11.4 ns |

"Simplex 比 Perlin 快"这个说法在二维并不成立：少算 1 个角，换来的是斜切、反斜切和三个四次方，在这里慢了 1.5 到 3.3 倍。Simplex 的速度优势在高维：三维是 4 个角对 8 个，四维是 5 个对 16 个（这是按角的数量推算的，本文没有实现三维以上的版本）。在二维选 Simplex 的理由是各向同性，不是速度。

我还试过把"半径外的角跳过"写成无分支的 `max(0, …)`：跳过与否几乎是随机的，分支预测会频繁失败。改成无分支后从 11.7 ns 降到 10.8 ns，提升不大。

<Aside type="note" title="专利">
Perlin 为三维及以上的 Simplex 噪声申请过专利（US 6,867,776），已于 2022 年到期。专利有效期间，社区开发了 OpenSimplex 等替代算法。二维版本从来不在专利范围内。

## Worley 噪声

Steven Worley 在 1996 年提出了一种完全不同的噪声：在平面上随机撒一些**特征点**，噪声的值是采样点到最近特征点的距离 F1。F1 在每个特征点处为 0，向外增大，在两个特征点之间的"分界线"上形成脊——整体看起来像细胞、鹅卵石或龟裂的泥地。

常用的还有第二近的距离 F2，以及 F2 − F1：它在分界线上为 0，在细胞中心最大，用来画裂纹、石板路的缝隙非常合适。

为了保持"确定、随机访问"，特征点不能真的随机撒，而是**每个格子放一个**，位置由格子的哈希决定。求 F1 时只需要查附近的格子：

### 3×3 够不够

几乎所有教程都只查周围 3×3 个格子。直觉是：最近的特征点不会离得太远。但这不是严格成立的：采样点所在格子的特征点可能在对角上，离它最远可达 √2 ≈ 1.41，而隔一个格子的特征点离它最近可以只有 1 出头。精确的做法是一圈一圈往外查，直到外圈的格子不可能比当前的 F2 更近。

暴力参照查 9×9 个格子。测试中 20 万个随机点上，精确搜索与暴力完全一致（逐位相等），而 3×3 搜索确实会出错。400 万个随机点上统计：

| | 3×3 搜索出错 | 最大误差 |
|---|---|---|
| F1 | 9 次（百万分之 2.2） | 0.054 |
| F2 | 415 次（万分之 1.0） | 0.178 |

F1 出错极少，F2 稍多。在 1024×1024 的贴图上，F2 大约会错 100 个像素，每个错误是一小片不连续的斑点。图 4.2a 打开 3x3 errors 就能找到它们。

更关键的是，**精确搜索并不更贵**：它平均只检查 9.09 个格子（大部分时候 3×3 之后就能确定停止），实测两者都是约 51 ns。所以没有理由用 3×3。

Worley 噪声比格点噪声慢得多（约为 Perlin 的 7 倍），因为每次采样要计算 9 个特征点的位置和距离。早期版本用 `std::hypot` 求距离，要 73 ns；改成比较距离的平方、最后再开方后降到 48~52 ns——`hypot` 为了防止中间结果溢出，写得很慢。

### Voronoi 图

按最近特征点所在的格子着色，就是**Voronoi 图**：每个区域里的点都离同一个特征点最近（图 4.2a 的 cells 模式）。画区域边界时，容易想到用"F2 − F1 小于某个值"，但 F2 − F1 并不等于到边界的距离，边界会时粗时细，在三条边界交汇处出现楔形的黑块。到边界（两个特征点的垂直平分线）的真实距离是

```
(F2² − F1²) / (2 · |p1 p2|)
```

所以 `CellSample` 同时记录了第二近的点所在的格子。4.7 会更系统地讨论 Voronoi 图与 Delaunay 三角剖分。

## 分形布朗运动

现在解决"只有一种尺度"的问题。做法很直接：把多层噪声加起来，每一层的频率是上一层的 2 倍（起伏更密），振幅是上一层的一半（起伏更矮）：

```
fbm(p) = Σ gainᵏ · noise(lacunarityᵏ · p)
```

第一层决定大的山脉，第二层在山坡上加出丘陵，第三层再加出更小的起伏……这样的结构在每个尺度上看起来都差不多，叫做**自相似**，自然界的海岸线、山脉、云都有这种性质。每一层叫一个 **octave**（八度，频率翻倍的意思），频率的倍数叫 **lacunarity**，振幅的倍数叫 **gain**（也叫 persistence）。

### 频谱：gain 决定斜率

fBm 的功率谱应当是一条直线。每升一层，频率乘 2，振幅乘 gain，功率乘 gain²；二维时这些功率分布在面积大 4 倍的频率环上，所以功率谱密度按 gain²/4 递减。写成幂律就是

```
PSD(f) ∝ f^(−β)，β = 2 − 2·log₂(gain)
```

gain = 0.5 时 β = 4。gain 越大，高频越强，地形越粗糙。对 6 层 fBm 做二维 FFT，拟合斜率：

| 底噪 | gain | 拟合斜率 | 理论 | 频谱的起伏（对数残差 RMS） |
|---|---|---|---|---|
| Value | 0.35 | −5.18 | −5.03 | 0.088 |
| Perlin | 0.35 | −5.00 | −5.03 | 0.097 |
| Simplex | 0.35 | −5.01 | −5.03 | 0.094 |
| Value | 0.50 | −4.08 | −4.00 | 0.052 |
| Perlin | 0.50 | −3.98 | −4.00 | 0.069 |
| Simplex | 0.50 | −3.99 | −4.00 | 0.067 |
| Value | 0.70 | −3.17 | −3.03 | 0.043 |
| Perlin | 0.70 | −3.01 | −3.03 | 0.046 |
| Simplex | 0.70 | −3.03 | −3.03 | 0.048 |

三种底噪都和理论吻合。这个结果推翻了我在上一章写下的一个判断：我曾认为 Value Noise 混有大量低频，叠加时各层会互相干扰，难以控制频谱。实际上 Value Noise 的斜率只比理论值陡 0.08~0.15，而且频谱的起伏**更小**——它的每一层本身就覆盖很宽的频段，层与层之间衔接得更平滑；Perlin、Simplex 是带通的，层与层之间的频谱上能看到轻微的波纹。上一章的那段话已经更正。选择底噪时，真正要考虑的是格点痕迹和方向性，而不是频谱斜率。

### 陷阱：整数点上恒为 0

Perlin 噪声在每个格点上都是 0。频率倍率为 2 时，第 k 层的格点间距是 1/2ᵏ，**所有整数点都是每一层的格点**。于是不加任何处理时，fBm 在每个整数点上都是 0，不管叠加多少层：

| 底噪 | 随机位置的标准差 | 整数点，各层对齐 | 整数点，各层加偏移 |
|---|---|---|---|
| Value | 0.265 | 0.339 | 0.274 |
| Perlin | 0.127 | **0** | 0.124 |
| Simplex | 0.316 | **0** | 0.331 |

（Simplex 的"整数点"是三角形网格的顶点，同样每一层都重合。）Value Noise 不为 0，但整数点上的标准差偏大，因为每一层都正好取到格点上的原始随机值。

修正方法是给每一层加一个非整数、各不相同的**偏移**（`octaveOffset`），或者每层旋转一个角度。偏移之后，三种底噪在整数点上的统计都回到了正常水平。测试中逐点检查了 41×41 个整数点：不加偏移时 Perlin fBm 精确为 0，加偏移后没有一个是 0。

### 偏移打不破 256 的周期

上一章提到置换表的噪声每 256 个单位重复一次。叠加成 fBm 以后呢？第 k 层的周期是 256/2ᵏ，都整除 256，所以 fBm 仍然以 256 为周期——**加了偏移也一样**，因为偏移只是平移，不改变周期。测试验证了这一点，也验证了把 lacunarity 改成 1.98 后周期就消失了。如果要用置换表做大地图，lacunarity 取一个不是 2 的数（如 1.98 或 2.01），或者每一层用不同的种子。

### 山脊与格点尖峰

ridged 把每层的值换成 `(1 − |n|)²`：噪声的零线变成尖锐的山脊，适合做山脉、闪电、大理石纹理。在图 4.2b 中切换到 ridged，频谱的高频部分会出现几个**尖峰**。

这是格点的痕迹。对单层噪声沿坐标轴做 FFT，看格点频率（每单位 1 个周期、2 个周期）处的功率与相邻频率之比：

| 单层噪声 | 每单位 1 周期 | 每单位 2 周期 |
|---|---|---|
| Perlin | 0.7 倍 | 1.2 倍 |
| ridged Perlin | **53 倍** | **59 倍** |
| Value | 0.8 倍 | 1.0 倍 |
| ridged Value | **73 倍** | **30 倍** |

我起初以为原因是"Perlin 在格点上为 0，所以 1 − |n| 在格点上都是 1，山脊穿过每个格点"。但 Value Noise 在格点上并不为 0，ridged 之后同样出现尖峰，说明机制更普遍：上一章测过，两种噪声的**标准差**都随格子内的位置周期变化（Value 在格点处大、中心处小；Perlin 相反）。噪声本身的均值处处为 0，所以看不出周期；但 |n|、n² 这类**非线性变换**的均值取决于标准差，于是周期变化的标准差变成了周期变化的均值，频谱上就出现了格点频率的尖峰。

这意味着不只是 ridged：下一章做地形时，对噪声取绝对值、平方、设阈值（"高于 0.3 是山"），都会把格点的周期带进结果。多层叠加和每层偏移能把尖峰分散到不同频率，但不能消除。

### 开销

6 层 fBm 的用时就是单层的 6 倍左右：Perlin 底噪 44 ns，Simplex 底噪 65 ns。一张 1024×1024 的 6 层高度图约需 45~70 ms，适合在加载时或后台线程按区块生成，不适合每帧重算。

Apple M3，Apple clang 21，`-O2`。测量时机器上有其他负载（平均负载 5~6），用时有 10%~20% 的波动。分布、频谱、错误率等统计是确定性的，与负载无关。代码在 `cpp/procgen/fractal/fractal_bench.cpp`。

## 测试

- **Simplex 与暴力写法逐点一致**：枚举附近全部三角形顶点、不判断所在的三角形，30,000 个随机点上两种哈希的最大误差小于 10⁻¹⁰；影响半径改成 0.6 后，超过 10% 的点不一致。
- **Simplex 的性质**：三角形顶点上为 0；解析导数与中心差分一致；跨过三角形的边时值与梯度连续；4096 种梯度组合穷举，绝对值不超过 1 且能取到 0.999 以上。
- **Worley 与暴力一致**：20 万个随机点，精确搜索的 F1、F2 与查 9×9 个格子的暴力逐位相等；记录的最近、第二近格子正确；3×3 搜索只会偏大，并且确实会出错；特征点在格子内均匀分布，x、y 偏移不相关。
- **fBm**：与逐层手算一致（普通与 ridged）；归一化后不超过单层的范围；不加偏移时整数点上为 0；置换表底噪以 256 为周期（加偏移也是），lacunarity 1.98 时不是。

变异测试：故意改坏 13 处，第一轮有两处没被发现：

- **ridged 少了平方**：原来只检查了范围在 [0, 1] 内。补上与手算比较的测试。
- **特征点的 x、y 用同一个哈希值**：所有特征点都落在格子的对角线上，图案明显不对，但精确搜索与暴力用的是同一个 `featurePoint`，结果仍然一致。补上分布检查（均值、方差、x 与 y 的相关系数）后可以发现。

补上后 13 处全部被发现。

## 常见陷阱

| 问题 | 原因 | 解决 |
|---|---|---|
| Simplex 噪声沿三角形的边有细微断层 | 影响半径取了 0.6 | 二维用 r0² = 0.5 |
| Simplex 输出超出 [−1, 1] 或偏小 | 照抄了针对另一组梯度的缩放系数 70 | 按自己的梯度集合重新求最大值 |
| 以为二维 Simplex 更快 | 它的优势在高维 | 二维时为各向同性选它，不是为速度 |
| Worley 贴图上偶尔有不连续的斑点 | 只搜索了 3×3 个格子 | 精确搜索，平均开销几乎一样 |
| Voronoi 边界时粗时细 | 用 F2 − F1 当作到边界的距离 | 用 (F2² − F1²) / (2·\|p1p2\|) |
| fBm 在整数点上全是 0 | 各层的格点重合 | 每层加不同的非整数偏移或旋转 |
| 叠加了很多层，地图还是每 256 格重复 | lacunarity 为 2，各层周期都整除 256 | lacunarity 用 1.98 之类；或每层不同种子 |
| 地形太平滑或太粗糙 | gain 决定频谱斜率 | gain 0.5 是常见起点；越大越粗糙 |
| 层数太多，生成很慢 | 每层的开销都一样 | 最高一层的格子小于一个像素就没有意义了，层数按分辨率决定 |
| ridged 或阈值处理后出现规则的纹理 | 非线性变换把格点的周期带进了均值 | 每层偏移、旋转；必要时换用 Simplex |

## 练习

1. **层数上限**：一张 512×512 的贴图，第 0 层画面宽度对应 4 个格子。第几层以后，格子小于一个像素？多加的层对图像还有影响吗？用图 4.2b 的频谱验证。
2. **旋转的层**：每层除了偏移，再旋转一个角度（比如 37°）。测量 Perlin fBm 的 E[cos 4θ] 和 ridged 的格点尖峰，与只偏移相比有什么变化？
3. **多重分形**：让每一层的振幅取决于前面几层的值，例如低处平坦、高处粗糙（Musgrave 的 hybrid multifractal）。它的频谱还是直线吗？
4. **Worley 的距离**：把欧氏距离换成曼哈顿距离或切比雪夫距离，观察图案的变化。精确搜索的停止条件需要怎样修改？
5. **三维 Simplex**：实现三维 Simplex 噪声，与三维 Perlin 比较速度，验证"高维时 Simplex 更快"。
